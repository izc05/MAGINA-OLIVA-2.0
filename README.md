# Mágina Oliva

Gestión del olivar para web y móvil, con React Native, Expo y TypeScript.

## Arrancar

```
npm install
npm run web
```

## Estado

Hecho: acceso de desarrollo, panel, lista de fincas y alta dibujando sobre la ortofoto PNOA (solo web).

Provisional: no hay servidor ni contraseñas, y los datos se guardan solo en el dispositivo. El clima y la consulta a Catastro y SIGPAC aún no están conectados; la referencia catastral solo se comprueba por su formato.

## Antes de contribuir

Los requisitos y las reglas están en `investigacion/REQUISITOS-MAGINA-OLIVA-WEB.md`, en la carpeta superior del proyecto. No se puede copiar ni usar como fuente material de otros productos.
